# Incident Room

Incident Room is a planned real-time incident coordination platform for engineering and operations teams. Dedicated incident rooms will combine operational context, a shared timeline, contextual discussions, and postmortem documentation.

**Current status:** Phase 0 — Final / Accepted. Implementation has not started.

The accepted [Product Specification](docs/product-spec.md) is the source of truth for subsequent phases.

## Planned frontend stack

React 19, Next.js, TypeScript, Redux Toolkit, TanStack Query, React Hook Form, Zod, WebSocket, TanStack Virtual, Tailwind CSS, Radix UI / shadcn/ui, MSW, IndexedDB where appropriate, Vitest, React Testing Library, Playwright, and GitHub Actions.

These are planned choices; no application scaffold, dependencies, or implementation are configured yet.
