## UX/accessibility inspection

Login/register associate validation and focus recovery. Filters retain URL/error state; no-match differs from first use. Timeline/Thread keep semantic lists/focused-row pinning, newline vs Cmd/Ctrl+Enter and IME guards; closing Thread restores opener/viewport. Search retains query, inbox preserves canonical navigation when mark-read fails. Palette owns modal focus/active descendant and editable shortcut guard. Postmortem uses labelled native controls and conflict/save feedback. Demo uses native details/fieldset/select/button, destructive confirmation and operation disabling. Existing shared tokens unify buttons/inputs/spacing/borders/focus; no aesthetic redesign or unused icon/motion package.

Phase 9 removes misleading landing/status copy, adds reviewer credentials/scenarios and real Team/Settings information. Token contrast reasoning and browser semantic checks are not full screen-reader/device testing. Remote HTTPS/assistive-device matrix remains unverified.

## Rendering/performance

Confirmed Timeline projection caches acquisition references; ephemeral typing/presence and draft changes do not reconstruct/sort history. Root summaries subscribe only at mounted rows; Thread windows stay bounded. Search scans authority rather than downloading all frontend histories. Badge uses absolute unread summary, not inbox enumeration. Postmortem RHF fields remain local; Demo stores small serializable scalars and binds existing coordinator capabilities outside Redux. No speculative global memoization.

Existing real 10k cases remain; Phase 9 adds 50k authority replacement/recent DOM and old target/Thread bounded DOM. These are functional sanity observations, not FPS/p95 promises. Whole authority buckets still validate/clone/write in native transactions; Search and polling can consume CPU at stress scale. Production would need indexed server queries/retention, not more UI memoization. Loaded Query windows/acknowledgments grow with deliberate acquisition; virtualization bounds DOM, not all memory.

Known local boundary: unchanged six-worker Phase 8 runs yielded 142/156 and 148/156; an old timeout reproduced with Phase 7 sources. Phase 8 CI #9 passed 309 unit/component and 156 browser tests with two workers, zero actual retries. Phase 9 uses the authorized stable two-worker/no-retry local configuration and independent normal CI. No worker/timeout/retry/assertion/CI weakening. Exact high-concurrency root cause remains unresolved; supported green runs do not prove six-worker stability.
